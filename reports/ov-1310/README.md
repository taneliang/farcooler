`.github/workflows/ci-runner-retry.yml` listens for completed CI runs. For a main push, `scripts/ci-runner-retry.py` finds Mac jobs cancelled without a runner or steps and with that exact annotation in the first attempt. It requests one job rerun at each completion, then checks subsequent attempts for jobs already rerun (including dependents) before selecting another. This covers independent simultaneous cancellations while limiting each job to one automatic retry. Test failures are not selected. The retry uses the default branch's trusted script and the original job's existing test definition. `scripts/ci-runner-retry-test.py` simulates two cancelled sibling shards, verifies both actual rerun API requests across successive completions, and verifies no third request.
