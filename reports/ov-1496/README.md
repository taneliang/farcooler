# ov-1496 — Native app removal in two stages

**Decision for ov-1489.** Approve phone retirement once the remaining Mac and relay checks are decoupled and the owner accepts the phone capabilities listed below. Approve Mac retirement conditional on ov-1488 proving an app-free Mac runner install, migration, and update from a signed release. The main improvement comes from stage 2. It removes 16m 06s of Swift job time on the green baseline and lets the retained macOS Rust shards start earlier. Stage 1 removes dormant phone jobs and about 2m 23s of active CI script work.

**Basis.** Tree at `7a08f9c10` on Nov 27, 2026 Singapore time. CI timing uses the first attempt of [green CI run 45861303727](https://github.com/taneliang/farcooler/actions/runs/45861303727), from the start of Changes to the last completed job. Times below are elapsed runner time. Release and scheduled jobs have separate triggers and are outside the per-push total.
