Getting Started

Far Cooler gives you, or your whole team, one orchestrator: an agent that keeps the priorities and the plan, runs the implementation through other agents, and brings you only the calls that are yours. Everything runs on machines you own.

What you need

  • A Mac with macOS 26 or later.
  • A runner, the machine your agents work on: this Mac, or a Linux computer you reach over SSH. A runner needs tmux and Git; on Linux it also needs systemd, which almost every distribution has.
  • An agent you’re signed in to on that runner: Claude Code, Codex or the Cursor CLI. Far Cooler runs them; it doesn’t replace them, and it uses your own login.

A Far Cooler account is optional. You need one for notifications on your phone, for adding a phone by scanning a code, and for teams.

Your first orchestrator

  1. Install the Mac app

    Download Canary for Mac and install it from the disk image. The app is signed and notarized by Apple, checks for updates once a day, and asks before installing one.

  2. Open it

    Far Cooler starts a small background service on this Mac, so agents keep working after you close the window. The welcome screen checks what this Mac has: the service, tmux, and which agents are installed. If something is missing, it says what and how to get it. It also offers to install the farcooler command for Terminal.

  3. Add a repository

    Choose a Git repository with Add Repository… (⇧⌘R). Agents never work in your own checkout: each piece of work gets its own folder and branch, so your checkout stays as you left it.

  4. Start the orchestrator

    Choose Claude Code, Codex or Cursor to be the orchestrator. The first time, it asks a few questions about how you like work done: whether work lands on main or through pull requests, what “done” means, who reviews, and what it may decide on its own. Your answers become the charter, a short file you can edit any time. Then tell it what you want built, in plain words, as much or as little at a time as you like.

    The orchestrator files the work as tasks, groups them into themes, and starts agents on them, each in its own lane. What you’ll see a few minutes in:

  5. Add a Linux runner (optional)

    Agents can also run on a Linux computer, so they keep working while your Mac is off. Choose Add a Runner by Address… and give it your SSH address, then install. Far Cooler copies itself to that account’s home folder over SSH; it needs no root and opens no port.

  6. Add your phone (optional)

    The iPhone and Android apps aren’t publicly available yet; until they are, they’re built from source. Once a phone has the app, you pair it with the Mac by scanning a code, with both devices signed in to the same account. See Phones and the Watch.

  7. Bring your team (optional)

    Create a team at farcooler.com/app and send an invite link. On your runner, Add Teammate adds a teammate’s device, and they talk to the orchestrator through their own rep. See Teams.
