Agents

The agents are the ones you already use, running exactly as they would in your own terminal.

Claude Code, Codex and Cursor

Far Cooler runs Claude Code, Codex and the Cursor CLI. Each is the vendor’s own program, signed in with your own account, in a real terminal on the runner. Far Cooler doesn’t bring a model of its own.

The terminals live in tmux on the runner, not in the app. Close the app, lose your connection, or restart the Mac app, and the agents are still working when you come back.

Terminals, or a conversation

Every agent is a terminal you can watch and type into. If you’d rather read and reply to Claude Code or Codex as a conversation, turn on Conversation view for Claude and Codex panes in Settings. It’s off by default, and the terminal is always one click away.

Your own terminals

Beside the agents, each repository has terminals you start yourself, for things like a dev server, and each task’s folder can have its own. They’re ordinary shells, kept alive the same way.
